# Superstore Sales Analysis

Exploratory data analysis on a real-world retail sales dataset (~9,800 orders), 
using Python, Pandas, and Matplotlib.

## Dataset
Superstore Sales Forecasting dataset (Kaggle) — source: 
https://www.kaggle.com/datasets/rohitsahoo/sales-forecasting

## What this project covers
- Data cleaning: converted date columns, checked and documented missing values 
  and duplicates
- Feature engineering: derived a "Shipping Days" metric from order/ship dates
- Exploratory analysis: sales by category, sales by region, monthly sales trend
- Key findings on category performance, regional differences, and seasonality

## Key Findings
- Technology is the top-selling category ($827K), closely followed by Furniture 
  and Office Supplies
- The West region leads in sales ($710K); the South region lags behind ($390K)
- Average shipping time is 4 days, with no data quality issues
- Monthly sales show a clear upward trend from 2015–2018 with recurring year-end spikes

## Tools used
Python, Pandas, NumPy, Matplotlib
